# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of TrailBird AI seriously. Because TrailBird AI runs 100% locally on device with zero server/telemetry communication, user audio data never leaves the local hardware.

If you discover a potential security issue or vulnerability:

1. **Do not create a public GitHub issue.**
2. Email details to the repository maintainer at security@satanic47.org or contact lead maintainers directly.
3. Include steps to reproduce the vulnerability.

We will acknowledge receipt of your vulnerability report within 48 hours and work on a fix promptly.
