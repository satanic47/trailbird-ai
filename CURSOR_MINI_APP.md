# Smart Tip & Bill Splitter (Built with Cursor AI)

A responsive single-page web app for calculating tip percentages, splitting dining bills per person, and toggling themes.

## 🚀 Two-Sentence Cursor Summary for MLH Submission

> Cursor AI scaffolded the entire HTML structure, CSS styling, and live JavaScript calculation logic from a single natural language prompt. It helped instantly debug edge cases (such as preventing division-by-zero when splitting bills) and added a clean dark/light mode toggle effortlessly.

---

## 🛠️ Features
- **Live Calculation**: Instant calculation of tip amount, total bill, and split per person.
- **Tip Presets & Custom Input**: Preset buttons (10%, 15%, 20%, 25%) and custom percentage field.
- **Dark/Light Mode**: Smooth theme switcher with custom CSS variables.
- **Zero-Dependency**: Pure HTML5, CSS3, and modern ES6 JavaScript in a single file.
